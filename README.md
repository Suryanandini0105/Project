
# Vehicle Rental Management System

## About
A beginner-friendly vehicle rental website built using HTML, CSS, and JavaScript.

## Features
- Displays four available vehicles.
- Shows the rental price per day.
- Allows customers to enter their name and phone number.
- Calculates the total rental price based on the number of days.
- Displays a demo booking confirmation.
- Responsive layout for different screen sizes.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Alternatively, use the Live Server extension in VS Code.

## Project Limitation
This is a frontend demonstration. It does not store bookings in a database or make real reservations.
